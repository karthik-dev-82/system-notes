Context Managers: Play With It

The same resource-management protocol, written two ways -- a plain class with __enter__/__exit__, and a generator wrapped in @contextlib.contextmanager. Pick a scenario and watch both arrive at the identical outcome.
What every with statement actually does: value = mgr.__enter__() # if this raises, __exit__ is never called try: BODY(value) except Exception as exc: if not mgr.__exit__(type(exc), exc, tb): raise # __exit__ returned falsy -> propagate else: mgr.__exit__(None, None, None)
