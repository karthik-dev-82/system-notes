Queue vs Deque: Play With It

Same enqueue cost either way. The front operation is where a plain list and a real deque genuinely diverge.
queue = []
queue.append(x) # enqueue -- O(1)
queue.pop(0) # dequeue -- O(n): shifts every remaining element left
from collections import deque
queue = deque()
queue.append(x) # enqueue -- O(1)
queue.popleft() # dequeue -- O(1): no shifting, ever
queue length: 0
total element-shifts so far: 0
What's happening right now
Enqueue always appends to the right end -- O(1) either way. The difference is dequeuing from the front. Watch the shift counter: in list mode it climbs every single dequeue; in deque mode it never moves, because deque is a doubly-linked chain of blocks with genuine O(1) access at both ends.
