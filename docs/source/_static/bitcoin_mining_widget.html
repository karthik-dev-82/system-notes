Worth knowing, beyond what's animated here
  • This is genuinely SHA-256, computed via your browser's native crypto.subtle.digest -- not a simulation. Real Bitcoin mining is essentially this loop (try a nonce, hash it, check the leading zero bits, repeat) at a difficulty around 80 bits instead of this widget's 8-18 -- the one difference is real mining hashes the block header twice (SHA-256d, i.e. SHA-256(SHA-256(header))), specifically to defeat a length-extension weakness that single SHA-256 has; the widget hashes once, which doesn't change anything about the search itself. Going from 18 bits to 80 bits isn't a little harder, it's roughly 262 times harder -- which is why real mining needs warehouses of specialized ASIC chips, not a browser tab.
  • A block's hash is never stored -- it's always recomputed. That's the entire trick this widget demonstrates: there is no cached "hash" field anywhere in this page's code that tampering could leave stale. Every block's hash is derived fresh from its current data, its recorded previous-hash, and its nonce, every single time anyone looks at it. Change one character of data and the hash is a completely different, unpredictable number (this is the avalanche effect -- SHA-256 is deliberately designed so similar inputs never produce similar outputs).
  • "Repair" is doing real work, not resetting a flag. When you repair a tampered block, the widget actually re-runs the mining search against the new data to find a valid nonce -- watch the attempt counter to see it happen. On a real network, this is exactly what an attacker rewriting history would have to do, for every block after the one they changed, faster than the rest of the network is finding new blocks -- which is the actual meaning of a "51% attack": out-computing everyone else combined, not breaking any cryptography.
  • See Bitcoin, Distributed Ledgers & Zcash Explained for the plain-language overview this widget is built from, including how this same proof-of-work mechanism fits into the bigger picture of transaction broadcasting and network-wide consensus.
