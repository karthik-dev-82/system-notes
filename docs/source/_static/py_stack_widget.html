Stack: Play With It

A stack is a list used one specific way: push and pop only ever touch the end. This demo uses that discipline to solve a real problem -- checking whether parentheses are balanced.
def is_balanced(expr: str) -> bool:
stack = []
for ch in expr:
if ch == '(':
stack.append(ch)
elif ch == ')':
if not stack:
return False
stack.pop()
return not stack

What's happening right now
Step through the expression one character at a time. Every '(' is pushed; every ')' pops the most recent unmatched '('. This is exactly how editors highlight matching brackets, and exactly what a JSON/XML/code parser does to check nesting is well-formed.
