A Toy Event Loop, Ticking

Three coroutines, one hand-built scheduler on the right. Each coroutine's only way to hand control back is an await (modeled here as a yield) -- the loop decides who runs next, entirely by checking whose wait is over.

while not all_done(tasks): for t in tasks: if t.sleeping and t.wake_at <= tick: t.ready = True if t.waiting_on.done: t.ready = True t.send_value = t.waiting_on.result for t in tasks: if not t.ready: continue result = t.coro.send(t.send_value) if result.done: t.done = True elif result.type == "sleep": t.wake_at = tick + result.ticks tick += 1
