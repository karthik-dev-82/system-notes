Worth knowing, beyond what's animated here
  • A bare string task is shorthand, not a separate type. test = "pytest" means exactly the same thing as test.cmd = "pytest" -- cmd is just the default when no type is specified. cmd runs as a direct subprocess (no shell, no pipes/&&); reach for shell specifically when you need those.
  • An array is shorthand for a sequence. release = ["test", "_build"] means the same thing as writing it out as an explicit sequence task. By default, one failure stops the rest of the sequence -- try checking "make test fail" and running poe release to see _build never even attempt to run. Then try poe checkup (which sets ignore_fail = "return_non_zero") with the same failure toggled -- both steps run, but the overall result still reports failure.
  • Task names starting with _ are hidden from poe's no-argument listing and can't be invoked directly by name -- try poe _build and watch it get refused, even though the exact same task runs fine as a step inside release's sequence. This is real, documented behavior, not a simulation quirk -- it's how projects hide internal implementation-detail tasks from the tasks a contributor is meant to run directly.
  • Extra arguments typed after the task name are appended verbatim to the underlying command -- poe test -v really does become pytest -v. This widget only demonstrates that passthrough on a directly-invoked leaf task (cmd/shell), which is the clearly documented case.
  • Two environment variables are always available inside any task: $POE_ROOT (the directory containing the task file) and $POE_PWD (the directory you actually ran poe from) -- useful because a task's own working directory can change during execution, but you often still need to know where the invocation actually started.
  • Not modeled here, but real: switch tasks pick a branch based on a "control" task's output (commonly control.expr = "sys.platform", to run different commands on different operating systems) -- worth knowing exists, even without its own interactive demo on this page.
