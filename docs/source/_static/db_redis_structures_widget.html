Worth knowing, beyond what's animated here
  • The sorted set never gets sorted after the fact. Every ZADD in this widget re-sorts immediately -- ties broken by member name, exactly like real Redis. That means ZREVRANK is never a search: it's just reading a position off a structure that was already correct the moment before you asked.
  • SINTER does real set math. Try Europe ∩ EUR -- all 8 EUR-currency countries are European in this dataset, so the intersection equals the smaller set exactly. Try Europe ∩ USD to see the other extreme: the United States isn't European, so the intersection is empty even though both sets are non-empty.
  • The TTL clock here is virtual, not real time -- you advance it yourself, one tick at a time, so the expiry moment is exact and repeatable rather than something you'd have to wait through. Once a key's tick has passed, no later GET ever brings it back -- there's no partial-credit "still a little fresh" state.
  • All four structures above are reading from the exact same 20-country dataset used in Databases: The Ultimate Guide for Young Engineers and in Index vs. Full Scan: Play With It -- the same USA, same Germany, same population numbers throughout.
