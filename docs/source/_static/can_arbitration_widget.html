Worth knowing, beyond what's animated here
  • The bus is a real wired-AND, modeled exactly. If any transmitting node drives a dominant bit (0) while others drive recessive (1), every node -- including the ones sending 1 -- reads back a 0. That's not a simplification for the demo; it's the actual electrical behavior of a CAN bus's two differential wires.
  • Every node reads back what it just sent, every single bit, transmitter or not. The instant a node notices its own bit doesn't match the bus, it already knows it lost -- there's no separate "collision detected" signal or timeout the way Ethernet needs one.
  • Zero bits of this frame are ever wasted. Compare that to Ethernet's CSMA/CD: a collision there is only detected after the fact, and the *entire* colliding frame has to be thrown away and retried after a random backoff. CAN's losing nodes simply stop mid-ID and wait for the current frame to finish -- nothing they already sent was wrong or needs resending.
  • This widget uses 8-bit IDs for a compact table; real CAN uses 11-bit (standard) or 29-bit (extended) identifiers. The mechanism -- dominant beats recessive, bit by bit, MSB first -- is identical at any width.
